## قواعد استفاده

- SVGها شماتیک آموزشی‌اند و هیچ دادهٔ کمی در آن‌ها وجود ندارد.
- پیکان نقطه‌چین به معنی مسیر محتمل/پیشنهادی است؛ پیکان یا برچسب را به ادعای اثربخشی مکمل تبدیل نکن.
- پیش از واردکردن ל-PPTX، متن فارسی، فونت و نشانه‌گذاری را در محیط هدف بررسی کن. برای خروجی کاملاً قابل‌ویرایش، دیاگرام را با شکل‌های بومی پاورپوینت بازسازی کن.
- این دیاگرام‌ها برای همین پروژه ساخته شده‌اند. هر تصویر بیرونیِ تازه باید منبع، مجوز، کپشن و محل استفادهٔ آن ثبت شود.
- اگر دیاگرام از نظر علمی تغییر می‌کند، منبع، نقشهٔ شواهد و دست‌نویس اسلاید مربوط را هم‌زمان اصلاح کن.
